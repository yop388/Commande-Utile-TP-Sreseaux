	KERNEL=="vmnet1", MODE="0666"
	KERNEL=="vmnet8", MODE="0666"
	
	3_: Appliquez immédiatement les règles sans redémarrer le PC :
	sudo udevadm trigger
	
OPTION B: Modifier le script de démarrage de VMware (La plus robuste)

	1_: ouvrez le script réseau de VMware:
	sudo nano /etc/init.d/vmware
	
	2_: Utilisez la fonction de recherche de Nano (Ctrl + W), tapez vmwareStartVmnet et appuyez sur Entrée.
	
	3_: trouver une section qui ressemble à ceci (où VMware démarre ses réseaux)
	vmwareStartVmnet() {
   	vmwareLoadModule "$vnet"
   	...
	
	4_: Allez juste à la fin de cette fonction vmwareStartVmnet() (juste avant le caractère } qui la ferme) et ajoutez cette ligne :
	chmod a+rw /dev/vmnet1 /dev/vmnet8
	
	5_: Sauvegardez et quittez (Ctrl + O, Entrée, Ctrl + X).



	:::::::::::::::: Exercice 5.1 & 5.3 — Configuration du Tunnel IPsec (Phase 1 & Phase 2) ::::::::::::::::

Justification des paramètres (Sécurité / Performance) :

		Chiffrement : AES-256 (solide et supporté matériellement par l'accélération ASIC/offloading).
		Hachage / Authentification : SHA-256 (évite les faiblesses de MD5/SHA-1).
		Groupe DH (Diffie-Hellman) : Groupe 14 (2048-bit) ou 19 (ECP256) pour garantir le Perfect Forward Secrecy (PFS).
		Clé partagée (Pre-Shared Key - PSK) : Chaîne complexe (ex: SecretKeyLab2026!).
		

CONFIGURATION :

        set interface "port1"              ; interface WAN du Siège
        set ike-version 2
        set peertype any
        set net-device disable
        set proposal des-sha256
        set dhgrp 14
        set remote-gw 192.168.13.137          ; IP publique de l'Agence
        set psksecret YaoKone@2026
    next
end

######### GUI:: permettre à notre réseau LAN d'accéder à Internet ::GUI ####

	1. Créer la règle de pare-feu (Firewall Policy)
		- Dans le menu de gauche, allez dans Policy & Objects > Firewall Policy (ou IPv4 Policy selon votre version de FortiOS)
		- Cliquez sur Create New (Créer une nouvelle règle)
		- Remplissez les champs avec les paramètres suivants :
			_ Name : Donnez un nom explicite (ex: LAN_to_Internet)
			_ Incoming Interface : Sélectionnez votre interface locale (ex: LAN (port2) comme visible sur votre capture).
			_ Outgoing Interface : Sélectionnez votre interface connectée à Internet (ex: WAN (port1)).
			_ Source : Sélectionnez all (ou le sous-réseau spécifique de votre LAN).
			_ Destination : Sélectionnez all (représentant Internet).
			_ Schedule : Laissez sur always.
			_ Service : Sélectionnez ALL (ou restreignez selon vos besoins aux protocoles HTTP, HTTPS, DNS).
			_ Action : ACCEPT
	
	2. Activer le NAT (Obligatoire)
	  Étant donné que votre réseau LAN utilise des adresses IP privées, elles ne peuvent pas naviguer sur Internet sans être traduites.
	
		- Faites défiler la page de configuration de la règle vers le bas jusqu'à la section Firewall / Network Options.
		- Activez l'option NAT (le bouton doit être vert).
		- Laissez l'option par défaut sur Use Destination Interface IP.
	
	3. Vérifier la route statique par défaut (Static Route)
	   Le routeur a besoin de savoir où envoyer le trafic destiné à Internet.
	   
	   	- Allez dans Network > Static Routes
	   	- Assurez-vous qu'une route par défaut existe :
	   		_ Destination : 0.0.0.0/0
	   		_ Gateway IP : L'adresse IP de la passerelle fournie par votre fournisseur d'accès Internet (FAI).
	   		_ Interface : Votre interface Internet (WAN (port1)).
	   	
	   	Après avoir cliqué sur OK pour enregistrer votre règle de pare-feu, les machines de votre réseau LAN devraient instantanément avoir accès à Internet.
