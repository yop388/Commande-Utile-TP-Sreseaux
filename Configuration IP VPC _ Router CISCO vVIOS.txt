:::::::: Pour configurer une adresse IP de manière permanente sur un VPC (Virtual PC / VPCS) ::::::::::

	1. Configurer l'adresse IP
		ip 192.168.1.10/24 192.168.1.1
	
	2. Enregistrer de façon permanente
		save
		
	3. Vérifier la configuration
		show ip


	4. Configuration DNS
		ip dns 8.8.8.8


:::::::: Pour configurer une adresse IP de manière permanente sur un routeur Cisco vVIOS (ou n'importe quel routeur Cisco IOS) dans EVE-NG, la logique est similaire ::::::::::::


	1. Entrer en mode de configuration
		enable
		configure terminal
	
	2. Configurer l'IP sur l'interface
		interface GigabitEthernet0/0
		ip address 192.168.1.1 255.255.255.0
		no shutdown
		exit
		exit
	3. Enregistrer la configuration de façon permanente
		write | copy running-config startup-config
	
	4. Configuration DNS
		configure terminal
		ip domain-lookup
		ip name-server 8.8.8.8
		exit
	5. Sauvegarde permanente :
		write
	
	6. Vérification :
		show system dns
		execute ping google.com
